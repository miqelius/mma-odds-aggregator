# 🥊 MMA Betting Intelligence Hub

A modern web application and intelligence platform focused on UFC/MMA news, automated updates, background odds monitoring, and an interactive MMA expert assistant.

## 🚀 Features

* **🔥 Automated UFC News & Analytics:** Real-time generation and display of the latest MMA news and predictions.
* **🌍 Multilingual Interface:** Seamless language switcher supporting Georgian (KA), English (EN), and Russian (RU).
* **🎨 Immersive Background Slideshow:** Dynamic, elegant background visuals featuring legendary fighters with smooth transitions.
* **🤖 MMA Expert Bot:** Interactive assistant interface for UFC insights.
* **📊 Background Monitoring:** Discreet tracking of active events, odds, and arbitrage opportunities.

## 🛠️ Tech Stack

* **Backend:** Python, SQLAlchemy
* **Frontend:** HTML5, CSS3, JavaScript (Responsive Dark Theme UI)
* **Deployment:** Render / GitHub
